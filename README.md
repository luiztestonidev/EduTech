# Sistema de Lanchonete

Projeto em Java para simulação de pedidos em uma lanchonete com interface de terminal.

---
## Tecnologias
- Java
- IntelliJ IDEA
---
## Funcionalidades
- Menu interativo no console
- Cadastro de pedidos
- Consulta de categorias
- Cálculo de valores
- Sistema de sorteio aleatorios e aplicação de desconto
---
## Como executar
1. Abrir o projeto na IntelliJ
2. Executar a classe Main
